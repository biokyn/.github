# BioKyn organization defaults

This repository holds the organization profile and the default community health files that GitHub applies to every BioKyn repository that does not define its own.

| File | Purpose |
|---|---|
| `profile/README.md` | Public organization profile |
| `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`, `GOVERNANCE.md` | Defaults for all repositories |
| `ISSUE_TEMPLATE/`, `PULL_REQUEST_TEMPLATE.md` | Default issue forms and PR template |

Edit here once; every repository without its own copy inherits the change.
