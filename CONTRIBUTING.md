# Contributing to BioKyn

Thanks for helping make bot protection private and accessible. The full guide lives with the code:
**[biokyn/biokyn CONTRIBUTING.md](https://github.com/biokyn/biokyn/blob/main/CONTRIBUTING.md)**.

In short: open an issue or discussion first for larger changes, keep pull requests focused, add tests, run `npm run check`, and sign off your commits (`git commit -s`).
